# 🌐 Personal Portfolio

A creative, interactive, and fully responsive personal portfolio website built with **HTML5**, **CSS3**, and **JavaScript**. Designed like an interactive desk setup featuring book overlays, custom contact shortcuts, a live time viewer, an interactive visitor note sheet, and an ID card modal.

## 🚀 Live Demo
Check out the live portfolio hosted on GitHub Pages:  
[👉 View Live Portfolio](https://saravanakumar070707.github.io/Saravana-Portfolio/)

---

## ✨ Features
* **Interactive Bookshelf Interface:** Clickable book spines that open up detailed overlays for **Projects**, **Skills**, **Resume**, **Experience**, and **About Me**.
* **Quick Contact Badges:** Direct links to LinkedIn, GitHub, Email, and WhatsApp.
* **Live Clock Modal:** Displays real-time India Standard Time (IST).
* **Interactive Visitor Note:** A quick, session-based scratchpad for visitors to jot down notes.
* **ID Card Viewer:** Popup student/professional ID card preview.
* **Fully Responsive:** Optimized for both desktop and mobile layouts.

---

## 🛠️ Built With
* **HTML5** — Semantic page structure and content.
* **CSS3** — Custom layouts, animations, transitions, and responsive design.
* **JavaScript (ES6)** — Dynamic book content rendering, modal controls, and live clock features.
